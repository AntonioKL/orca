Highest-value missing coverage

Windows behavior

  • WSL restore and shell-resolution parity for PowerShell 5/7, cmd, Git Bash, WSL, and missing shells.
  • ConPTY keyboard reset after agents/TUIs and modified-Enter routing.
  • Windows CJK/wide-glyph repaint and pixel-refresh correctness.
  • Windows input throughput and terminal backpressure budgets.
  • Startup color-query leakage, restore convergence, and persisted-session recovery.

Cross-platform live journeys

  • Paired-runtime and remote browser/terminal journeys with Linux and Windows clients.
  • Real sleep/wake, network partitions, multi-client churn, and reconnect behavior.
  • WSL-specific live process and PTY restore evidence.
  • Mixed-version client/host journeys in both skew directions.
  • CI soak history and per-OS flake tracking.

Recommended order

  1. Add a Windows Playwright smoke lane covering golden flows, terminal restore/input, file-browser drives, titlebar, settings, and onboarding.
  2. Wire ConPTY keyboard reset, shell parity, and CJK repaint into executable reliability gates.
  3. Promote Linux and Windows paired/SSH journeys from contracts to live CI evidence.
  4. Add explicit unit/integration/E2E/performance classification so coverage reports do not rely on filename heuristics.
  5. Track pass history and flake rate per OS.
